# Abhay Jaiswal — Data Engineer Portfolio

## Run locally
Open `index.html` directly in a browser, or run:
`python -m http.server 8000`

Then visit `http://localhost:8000`.

## Before publishing
1. Replace `your-email@example.com`.
2. Replace the LinkedIn and GitHub URLs with your real profiles.
3. Add your real project links/case studies.
4. Optionally replace the pipeline illustration with your own profile/project image.

The site is a single-file, responsive portfolio with animated pipeline visuals, scroll reveals, hover effects and reduced-motion accessibility support.
